# Run the bot 24/7 on a Linux VPS

This guide assumes a **Linux VPS** (Ubuntu or Debian-style) with **systemd**, **Python 3.12+**, and a **non-root** user that owns the bot process and files.

For CLI options (including `--no-plot`), see [CLI reference](../usage/cli.md). For configuration, see [Configuration](../configuration/config-file.md) and [Environment variables](../configuration/environment-variables.md).

---

## 1. Create a dedicated user

As root (or with `sudo`):

```bash
sudo adduser gridbot
```

Use a strong password or SSH keys only. You can skip adding `gridbot` to `sudo` if you will administer the machine from another account.

Log in as that user for all install steps below:

```bash
ssh gridbot@YOUR_VPS_IP
```

---

## 2. Install system dependencies

```bash
sudo apt update
sudo apt install -y git curl build-essential python3.12 python3.12-venv
```

Install **[uv](https://docs.astral.sh/uv/)** using the official instructions (typically a one-line installer). Ensure `uv` is on your `PATH` (often `~/.local/bin` — add it to `~/.bashrc` if needed).

Verify:

```bash
python3.12 --version
uv --version
```

---

## 3. Clone the repository

```bash
cd ~
git clone https://github.com/jordantete/grid_trading_bot.git
cd grid_trading_bot
```

If you use a fork or private copy, use that URL instead.

---

## 4. Install the application

From the repository root:

```bash
uv sync
```

This creates `.venv` and installs runtime dependencies. Use `uv sync --all-extras` only if you need optional extras defined in `pyproject.toml`.

Confirm the entrypoint:

```bash
.venv/bin/grid_trading_bot --version
```

---

## 5. Configure the bot

1. Place your **`config/config.json`** in the repo (copy from your workstation with `scp`, or edit on the server).
2. Add **`.env`** or other secret files if your setup uses them (see [Environment variables](../configuration/environment-variables.md)).

Restrict permissions:

```bash
chmod 600 ~/grid_trading_bot/config/config.json
chmod 600 ~/grid_trading_bot/.env   # if present
```

Ensure your home directory is not world-readable (`chmod 700 ~` is typical).

Double-check **paper vs live** mode and API permissions before going live.

---

## 6. Manual test (before systemd)

From the repo root:

```bash
cd ~/grid_trading_bot
.venv/bin/grid_trading_bot run --config config/config.json --no-plot
```

`--no-plot` avoids opening Plotly in a headless environment. Confirm the bot starts without errors, then stop with **Ctrl+C**.

---

## 7. systemd service

Create a unit file as root. Adjust **`User`**, **`Group`**, and paths if your username or home directory differs (`getent passwd gridbot` shows the home path).

**`/etc/systemd/system/grid-trading-bot.service`**

```ini
[Unit]
Description=Grid Trading Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=gridbot
Group=gridbot
WorkingDirectory=/home/gridbot/grid_trading_bot
Environment=PYTHONUNBUFFERED=1

# Optional: load secrets (do not put API keys directly in this file)
# EnvironmentFile=/home/gridbot/grid_trading_bot/.env

ExecStart=/home/gridbot/grid_trading_bot/.venv/bin/grid_trading_bot run \
  --config /home/gridbot/grid_trading_bot/config/config.json \
  --no-plot

Restart=always
RestartSec=10

NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

Reload systemd, enable start on boot, and start now:

```bash
sudo systemctl daemon-reload
sudo systemctl enable grid-trading-bot.service
sudo systemctl start grid-trading-bot.service
```

---

## 8. Verify operation

```bash
sudo systemctl status grid-trading-bot.service
journalctl -u grid-trading-bot.service -f
```

After a **reboot**, confirm the service is active:

```bash
sudo systemctl status grid-trading-bot.service
```

---

## 9. Day-to-day operations

| Task | Command |
|------|---------|
| Restart after config change | `sudo systemctl restart grid-trading-bot.service` |
| Stop | `sudo systemctl stop grid-trading-bot.service` |
| View recent logs | `journalctl -u grid-trading-bot.service -n 200 --no-pager` |
| Update code and deps | `cd ~/grid_trading_bot && git pull && uv sync` then `sudo systemctl restart grid-trading-bot.service` |

Watch **disk usage** (logs, SQLite state, and any log files the bot writes). Use log rotation or the [monitoring stack](../monitoring/setup.md) if you run Grafana/Loki.

---

## 10. Security checklist

- Run the bot as a **dedicated user**, not root.
- **Firewall**: allow only SSH (and any ports you truly need).
- **SSH**: keys preferred; disable password login if appropriate.
- **API keys**: minimal permissions; disable withdrawal on the exchange if supported.
- **Secrets**: never commit `config.json` or `.env` with live keys.
